# Orbis

> Drop a product or a niche, get its world.

Orbis 是一个开源 AI Agent 工具，产品经理快速了解一个产品所在的市场格局、帮助创业者快速了解一个赛道适不适合加入

---

## 它能做什么

Orbis 提供两个功能，用户在首页选择其一：

### 产品 → 赛道

输入一个产品名称，Orbis 会告诉你：

- 这个产品属于哪个垂类赛道
- 这个赛道里有哪些类似的产品
- 这个产品的目标用户是谁，解决了什么痛点
- 各个产品的定位和差异
- 赛道里还有哪些空白点没人做

**适合**：想搞清楚自己产品处于哪个战场的人。

---

### 赛道 → 产品

输入一个模糊的赛道描述（比如"AI陪伴类"、"帮人记笔记的"），Orbis 会告诉你：

- 这个赛道的市场规模和增长趋势
- 目标用户是谁，他们的核心诉求是什么
- 赛道里有哪些产品，格局怎么分布
- 市场竞争烈度如何，机会在哪里
- 如果现在想要加入战场，是否是合适的

**适合**：想进入某个赛道前做调研的人。

---

## 交互流程

### 第一步：选择模式

打开 Orbis，首页选择"产品 → 赛道"或"赛道 → 产品"。

### 第二步：输入内容

- 产品模式：输入产品名称，例如"Notion"
- 赛道模式：输入模糊描述，例如"帮人管理知识的工具"

### 第三步：AI 开始分析

分析过程分多个节点依次执行，每个节点完成后立即展示该节点的结果，用户可以实时看到分析过程逐步展开，而不是等待一个黑盒转圈。

### 第四步：遇到歧义时，AI 会提问

当 AI 判断输入有歧义或信息不足时，会暂停并向用户提问，附带几个选项供选择。用户选择后，分析继续。

例如：

```
输入"Notion"后，AI 发现它横跨多个方向，暂停并提问：

  Notion 覆盖多个方向，你更关注哪个赛道？
  ○ 笔记 / 知识管理
  ○ 项目管理 / 协作
  ○ 个人 All-in-one 工作台

用户选择后，AI 继续分析。
```

### 第五步：查看完整报告

所有节点执行完毕后，输出一份完整的结构化报告。报告中所有竞品信息均附带真实来源链接，可自行验证。报告支持导出为 Markdown。

---

## 核心特点

- **实时搜索**：所有数据在分析时实时获取，不依赖过时的静态数据库
- **过程透明**：每个分析节点的结果实时可见，不是黑盒
- **主动提问**：遇到歧义不瞎猜，暂停询问用户
- **有据可查**：所有结论附带来源链接
- **中文互联网优先**：搜索策略专门针对国内市场优化
